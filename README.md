# 단테의 노트 (Dante's Note)

림버스 컴퍼니 거울 던전 도우미 안드로이드 앱.

- 떠 있는 '단테' 버튼을 누르면 현재 화면을 캡처해 한국어 글자를 읽고(Google ML Kit, 기기 내 처리),
  화면에 보이는 E.G.O 기프트를 찾아 덱 키워드·보충 키워드·합성·회복/부활 우선순위로 추천 순위를 띄웁니다.
- 화면을 읽기만 하며 게임을 조작하지 않습니다.

## 설치
GitHub Actions가 `main`에 푸시될 때마다 APK를 빌드해 **Releases → latest** 에 `DantesNote.apk`로 올립니다.
